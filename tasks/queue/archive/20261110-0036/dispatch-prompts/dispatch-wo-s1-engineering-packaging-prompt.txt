## 2. 执行顺序（按 PK-01 → PK-05 逐单元，Gate PASS 再进下一条）

### PK-01 EXE 单文件封装（Gate：零依赖环境可双击运行 + 运行期窗口枚举：宿主 GUI 可见、其余计数 0）
- 在 `tools/packaging/` 新建封装脚本（PowerShell 或 py 均可，须可复现）：调用 dotnet publish（设 DOTNET_ROOT），参数自包含单文件：`-c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true`，输出到 `dist\`。
- 注意 HostShell 是 WinUI3（UseWinUI=true），单文件发布需确认 WindowsAppSDK 自包含兼容性；若 WinUI3 单文件方案存在已知不兼容（WindowsAppSDK 1.8 对 PublishSingleFile 的限制），如实登记并在封装脚本中给出**已验证**的替代形态（如自包含目录发布 + 单文件引导器），验收口径不降级：产物必须零依赖双击运行。
- **Gate 证据**：发布命令与产物文件清单（路径/大小/SHA-256）、零依赖环境（或最小环境）双击运行实测记录、运行期窗口枚举（EnumWindows + IsWindowVisible）结果：宿主 GUI 窗口可见、其余窗口计数 0（N7 绝对纪律）。
- 禁止：任何前台弹窗、改变宿主壳功能逻辑、改动 `src/` 下的源码（只读引用）。

### PK-02 安装包制作（Gate：可双击安装、快捷方式存在、卸载项存在且可卸）
- 用 Inno Setup 6 编写 `tools/packaging/UltimaAgentSetup.iss`（或 .iss 模板 + 构建脚本）：AppName=Ultima Agent、版本资源/图标、开始菜单快捷方式、卸载项（UninstallDisplayIcon 等）、输出 `dist\UltimaAgent-Setup-<ver>.exe`。
- ISCC 调用：`& 'C:\Users\Administrator\AppData\Local\Programs\Inno Setup 6\ISCC.exe' <script>`。
- **Gate 证据**：ISCC 编译成功、安装包存在、真机实测安装成功（开始菜单快捷方式存在）、卸载项存在且实测可卸（卸载后残留检查：目录/快捷方式清除）。
- 禁止：安装过程中弹窗打扰（静默安装参数支持）、写死版本号 1.0.0（按 PK-01 实际产物版本）。

### PK-03 依赖引导（Gate：WebView2 缺失时静默安装零弹窗；已有则跳过）
- 在 Inno Setup 脚本中实现 WebView2 Runtime 检测（注册表/已知路径）与缺失时的引导：下载官方 Evergreen Bootstrapper（https://go.microsoft.com/fwlink/p/?LinkId=2124703）静默安装（`/silent /install`），或登记 Inno Setup 的 webview2 支持；安装全程零弹窗（N7）。
- **Gate 证据**：检测逻辑实测（本机已有 WebView2 → 跳过路径验证）；缺失模拟路径若无法在本机实测，如实登记"仅真机预期 + 逻辑走查"，禁止冒充已验证。
- 禁止：引导安装出现任何前台窗口/交互提示。

### PK-04 安装包签名（Gate：签名可验、篡改拒绝；无真实公钥 fail-closed）
- 复用 `tools/publisher/ultima_publisher/signing`（工单⑧ RU-11 同钥机制，Ed25519 双签名、私钥加密 PKCS#8 PEM、篡改拒绝 InvalidSignature）：为安装包增加签名/验签集成。
- 用临时测试密钥完成机制验证：签名安装包 → 验签 PASS → 篡改 1 字节 → 拒绝。
- **Gate 证据**：签名/验签命令与输出、篡改拒绝实测。**真实签名项明确标 BLOCKED（真实密钥待 L8 注入）**，不伪造。
- 禁止：生成/落盘真实发布私钥、私钥明文入库。

### PK-05 对接更新通道（Gate：安装包即更新资产，契约对接完成）

- **Gate 证据**：manifest 样例 JSON + 字段与 update-manifest-schema.md 逐字段核对记录。真实端到端上传/拉取闭环明确标"留待工单⑧ 联合收口"，不伪造。
- 禁止：创建 GitHub Release、真实上传、改写工单⑧ 发布工具。
