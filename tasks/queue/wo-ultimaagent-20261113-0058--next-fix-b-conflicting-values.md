## 3. 任务明细（三段式）

### T1 · 上下文预算自洽（E-02）

**文件**：基线 §16.2、§16.4；新增 §25.3 的预算引用行
**写什么**：
1. 复算并写明冲突：输入预算 4000 ＋ 输出上限（decision 256／dialog 512／摘要 512）＞ `n_ctx` 4096。
2. **A 案（动态预算）**：`input_budget = n_ctx − max_output(profile) − template_overhead`，给出公式与各 profile 结果表（数值由公式算出，不手填）。
3. **B 案（抬 n_ctx）**：`n_ctx` 提到 8192 的代价（内存/首 token 延迟）与回读门如何改。
4. 推荐 A（不改硬件承诺），但**最终由 Owner 裁决**；本单只落"待裁决"标记与两案数据，不写死结论。

**验收（Gate T1）**：冲突算式可复算；两案各有量化表；正文出现"待 Owner 裁决"标记；`n_ctx` 字面值未被改动（diff 可证）。
**禁止**：直接把 4000 或 4096 改掉；只写"建议调大"而不给算式。

### T2 · 全卷满承诺（E-04）

**文件**：基线 §17.2.3（L904 附近）
**写什么**：
1. 指出"无可写介质仍承诺排队不丢＋审计照写"不可实现：排队需要持久介质，审计追加同理。
2. **A 案（预留应急日志）**：固定预留 `emergency_journal`（容量与位置需给出建议值，标"待裁决"），全卷红时写应急区，恢复后回灌。
3. **B 案（改承诺）**：改词为"采集任务排队等待，**不保证不丢**；审计写入失败记事件并继续服务"。
4. 无论 A/B，均需写明"全卷满"的判定输入（卷状态来源）与可观测事件名。

**验收（Gate T2）**：原文承诺句被替换或加限定；A 案容量/位置有建议值并标待裁决；B 案改词逐句可 diff；事件名唯一。
**禁止**：保留"不丢、不失败"原句不改而只加注释。

### T3 · 容量与卸载口径互斥（E-05）

**文件**：基线 §14.1（L461 附近）、§17.2.3
**写什么**：
1. 列 §14.1 与 §17/§24 冲突三项：单库硬顶、库内删除、卸载门。
2. 在 §14.1 就地加"**已被 R-65/R-66/R-80 取代**"的废止行，并指向现行章节；保留历史值但标"作废"。
3. 校准"卸载默认保留"（§16.1）与"删除不清用户数据"的一致表述。

**验收（Gate T3）**：三处冲突各有废止或对齐处理；全文不存在两个互斥的现行门；作废标记可检索。
**禁止**：删历史（只标作废）；另立第三套容量口径。

### T4 · 拓扑与职责收敛（E-03、E-06、E-08、E-09）

**文件**：详解页 L147／L238／L292 区段、架构树"Middleware 沙箱"/"Shell 自愈"节点、基线 §16.5 与 Owner 日志 R-29
**写什么**：
1. **E-03**：把 Job Object 从"Middleware"节点移到"Shell 进程沙箱"；Middleware 只留 `fileDomain` 写域策略。两处节点 desc 同步改。
2. **E-06**：把 L147「进程全部在客户端域」与 L238「进程留在客户端域是刻意选择」改为"壳与呈现在客户端域；Console/queue_engine 在 Python 引擎域同 pid"，与 L382 一致。
3. **E-08**：二选一——A 给 Shell 根进程可重入重拉（引 §15 七道闸的归属令牌）；B 删去"常驻自愈"承诺，改"仅子进程可恢复"。不两者并存。
4. **E-09**：产出**唯一现行主脑职责表**（融合 R-29 三职责与 §16 五职责），旧表述标"作废/被本表替代"。

**验收（Gate T4）**：Job 只挂一处；详解页三处 Console 域表述一致（"客户端域"命中 0）；Shell 自愈单一口径；主脑职责表唯一且旧文标替代。
**禁止**：只改文案不改节点归属（E-03 必须动树）；把两份职责表并列当"两种口径"。

### T5 · 插件可停性与多端收窄（E-07、C-13）

**文件**：注册分类 §三、基线 §18、架构树多端调度节点
**写什么**：
1. 给每个插件三档标注：`disableable`／`runtime_required`／`install_time_only`；写明"任一可停"只适用第一档。
2. 渲染/安装所需插件列为不可停，并给停用后果。
3. **C-13**：v1 把多端调度收窄为"单用户、单显示端"，节点 desc 注明"多端调度为 v1.x"，或删除该节点并记入变更。

**验收（Gate T5）**：插件清单每条有档位；"任一可停"的适用范围被限定；多端节点有 v1 处置（收窄或移除）且与 R-49/F1 一致。
**禁止**：给所有插件统一标"可停"；保留无消费者的调度节点却不标版本。

### T6 · 总验收

**验收（Gate T6）**：9 条各有关闭证据（章节/行号）；所有涉及数值处均标"待 Owner 裁决"且未被改写；基线 diff 仅限指定章节；附录 A 记一行。
**禁止**：以"优化"名义顺手改其他参数。
