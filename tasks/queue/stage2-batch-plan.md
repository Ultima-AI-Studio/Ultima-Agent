## 二、逐单任务表（范围冻结）

### S11 学习闭环（M21 深化）

| T# | 任务 | 验收要点 |
|---|---|---|
| T1 | 轨迹采集标准化：从 audit_log 提取执行轨迹（意图/工具/结果/耗时/成败），输出可评测的 trace 记录 | trace 字段齐全、可回放 |
| T2 | 评测器：对批次轨迹评分（成功率/耗时/兜底命中），输出评测报告与基准线 | 评分可复算、基准线落盘 |
| T3 | 改进闭环：根据评测结果调整范式参数（如重试策略/工具优先级），沉淀用例进回归集；不做模型微调 | 调整有留痕、用例进回归、回归全绿 |

### S12 系统体检自动修复闭环（M16 扩展）

| T# | 任务 | 验收要点 |
|---|---|---|
| T1 | 体检问题分级：体检结果按 severity 分级（P0 阻塞/P1 影响/P2 建议） | 分级规则明确 |
| T2 | 修复提案生成：对可修复项生成具体修复动作提案（改什么/影响面/回滚方式） | 提案字段完整 |
| T3 | 先报告后执行：修复前征询（悬浮球/文本载体），用户批准才执行；高危自动拒 | 审批门生效、未批准不执行 |
| T4 | 修复执行与回执：执行修复 → 复检 → 回执落盘 | 复检证据存在 |

### S13 宿主抽象层（M25 前置）

| T# | 任务 | 验收要点 |
|---|---|---|
| T1 | 宿主接口定义：IO（输入/输出）、渲染（画布/窗口）、事件三组抽象接口 | 接口文档化、与 ADR-001 三层一致 |
| T2 | Windows 宿主适配：现有 Win32/WebView2 壳实现抽象接口 | 现有壳行为不变（回归全绿） |
| T3 | 跨平台验证预留：接口不绑定 Windows 技术栈（Python 3.13 基线） | 静态检查无平台绑定 |
