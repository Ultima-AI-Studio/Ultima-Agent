# 单来源前缀独立验收口径

只评审本次首份实际模型输出、实际原始来源/视图/引用表与运行证据，不读历史模型输出，不向后续作者输入评审答案或标准报告。前缀没有研究文件，不能判E02或整体任务成功。

机械与事实分别判定，联合PASS才可继续。机械门：指定当前模型/摘要/daemon、原自然query/原材料及sourcehash未变；真实NativeReAct/ToolCall/受限内存stage和SDK事件；一次nativePOST、max_turns=1真实终止；没有writer/ack/第二POST；raw/secured/schema一致；一次票据与request/source/read/view/d绑定，不能跨来源重解；所有提交引用在可见且未修改的原行；最终SDK END/caller确认<=冻结绝对d，t0含材料载入和锁等待，d<=首轮b+36；所有失败/拒绝/unused及teardown如实保留。SDKmax_turns_exceeded是受控前缀的真实停止原因，不等于模型生成被截断；rawresponse仍须done stop/完整/正计数。

事实门：逐条检查每个claim，以其提交的锚点加补充行段共同判断是否支持完整句子；多段可以共同证明条件与结果，不要求每一段单独包含整项复合命题。较宽原文用于检查主语、否定、先决条件、替代路径和限制，不可替代缺失的提交引文。代码操作须准确且原样qualified operation；文档宣称与代码实现分开。不得从导入、参数名、邻近章节或两个项目名字相似推断能力/集成；有效ID/语法/字节相同都不是事实成立证书。

单节价值：应说明当前文件对原问题的具体作用和必要机制/条件，允许简洁措辞，不要求枚举所有函数/每条异常分支。凡主张的含义受未提条件影响，须带正确限定；其余没有作出的主张不要求逐一罗列。无关摘录、错误主语/错误省略、完整主张无支撑、引用不对应或实际时限不合格均FAIL。S2首个代码前缀的拒绝/unused仍未证明本假设，停止后续；其余来源的合法unused必须独立核对其理由和剩余主题/至少3来源可行性，不能吞掉错误生成/事实错误或超时。

输出review.md+review.json，top verdict PASS/FAIL，分别mechanical/factual/coverage，逐claim记录提交位置、支撑/反例和必要条件，引用来源原行号，记录当前packet/response/view/sourcehash。尚无原始模型结果则不得事实PASS。单节PASS只证明这一份的有限表现；完整只读组还需>=3相关去重来源、原问题整体内容与项目边界覆盖，随后产品实现与正式E02真实文件/三轮另验。
