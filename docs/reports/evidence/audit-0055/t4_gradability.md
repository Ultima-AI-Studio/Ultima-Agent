# T4 · 验收门可机检性抽验

## 分类口径

- **可机检**：输入、观测对象和 PASS/FAIL 期望均客观；可直接组成一次自动化断言。
- **半机检**：目标值客观，但样本、扫描范围、身份选择、时钟或白名单未锁定，必须先由人补参数/夹具。
- **不可机检**：判定依赖语义理解或人工抽样，原文没有可执行的机器判据。
