# T3 · 18 条 Gate 可判定性

## 汇总结论

- 18/18 已判：**可机检 1，半机检 12，不可判 5**。
- 指定含糊词扫描：`合理` 0、`适当` 0、`基本` 0、`视情况` 1。
- `视情况` 唯一命中在 0057 Gate T2（0057 L67）。即使上下文是“禁视情况”，仍依本单“出现即不可判”的字面规则判该 Gate 不可判；修订时应把含糊词本身移除，改写为确定字段/表达式。
