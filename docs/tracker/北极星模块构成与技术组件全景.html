Senses.Voice ─E-01→ Core ─E-03→ Console ─E-04→ Middleware ─E-05→ Shell
Core ─E-02→ Memory ｜ Console ─E-07→ Surface ｜ 治理⑤ ─E-08 约束→ 各块
