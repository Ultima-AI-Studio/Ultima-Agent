Preserve the original class/registry/tool instances and source files. Observe WorkLedger.record at its request-local pre-composition boundary for the original adapter result/IDs. Pair each original SDK ID with that observed adapter record through original return metadata and actual event evidence. Missing, ambiguous, duplicate or inconsistent capture fails; no backfill from collection.trace_json, attempts_json, replay, final packet or quarantined members. A failed original operation remains failed. Separate observed/not-reached/unknown and fixed bounded error categories.

Nonmatching calls forward once without capture. The composition SDK tools have different names and must not enter this collector. Apply safe/closed publication checks to the independently captured evidence as required by the existing design.
