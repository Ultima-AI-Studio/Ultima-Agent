## 2. 每版明细（引用不复制）

### v0.1 环境基线
- **范围**：宿主壳骨架（WinUI3 + WebView2 渲染就绪 + 悬浮球占位）；环境门 9 项（environment-spec）；任务库接入 project-flow 七阶段。
- **不做**：语音链路、组合窗口、真实场景闭环（仅空任务库走通）。
- **验收**：空任务库端到端（立项→派发→收尾）PASS + 环境门全绿。

### v0.2 语音链路 PoC
- **范围**：CV3（CosyVoice3 合成 + sherpa-onnx 识别/VAD）接线；语音进/出可用；音色 PoC（训练环境已就绪，OPEN-07 已确认）。
- **不做**：音色训练定制（"沉稳男声"——非 MVP 依赖，回补条件：语音链路 PoC 通过）。
- **验收**：语音"查任务状态"→ 文字意图可识别（真机测试）。

### v0.3 任务场景闭环（文本）
- **范围**：L1 意图（查任务状态/默认不打断）→ L2 任务域 → L3 队列状态源（复用 dev-conductor 工单化 + legacy loop 经验，M7 显式引用）→ L4 编排 → L5 聚合汇报。
- **不做**：语音汇报（v0.4 起）、窗口组合（v0.4）、队列调整（v1.0）。
- **验收**：文本一句话查任务队列 → 聚合汇报（20 个任务 1 个失败：结论先行/异常优先/按需下钻）。

### v0.4 组合窗口 + 悬浮球
- **范围**：L4 积木组合窗口（组件树 DSL + schema 校验，ADR-007）；L6 窗口+语音同时交付；图波主题 v1 + 悬浮球状态绑定（theme-standard §4）。
- **不做**：队列调整（v1.0）、L8 受控执行完整（v1.0 骨架先行）。
- **验收**：窗口内容覆盖任务域清单 ≥90%；悬浮球四状态（倾听/思考/说话/待命）绑定正确。

### v1.0 MVP 冻结
- **范围**：L7 征询闭环（"你觉得怎么样"→调整→重呈现）+ 队列调整（插队/改优先级）；L8 凭证中心 + 受控执行（状态只报告、操作需授权）。
- **不做**：§7 不做清单全项（设备集群/macOS/Linux/云端同步/固定业务页面等，回补条件见 product-plan §7）。
- **验收**：product-plan §8 成功信号全绿（闭环率≥80%、覆盖≥90%、越界拦截 100%、诚实边界 100%）+ DoD 项目级 PASS → 打 tag `stage1-v1.0-frozen`。
