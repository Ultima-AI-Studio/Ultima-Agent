## 一、呈现层级重排（五类 → 三类）

```
① 基础能力（六块）
   Core / Senses.Voice / Shell / Surface / Memory / Middleware
   ＋ Console（引擎中心管理调度器，Manager 同进程子模块）
   ＋ 治理与约束 ⑤（横切：行为/输出/规则库/防投毒/审计独立/外发红线）
② 外部能力（容器）—— 三个抽屉
   能力库 Skill ｜ 插件 Plugin ｜ 模型库 Provider（**不含主脑**）
③ 交付
   Update / Lifecycle
```

- **Skill 与插件不再是第一层节点**，统一沉到外部能力之下；模型配置（大模型 API 列表）同属外部能力。
- 树的可视版本见 `next-基础能力盘点与缺口清单-20261113.md` §1.1.1（唯一呈现层权威），本节只做摘要对照。
