## 2. 最终口径（逐条）

### ① `LINK:` 取证范围 —— **采纳**

- 口径：只证明 **link 对象与其指向文本**（`LINK:<sha256(readlink 文本)>`），**不**递归证明目标内容。
- 必须写明的残余：只有目标路径本身进入本次 Git 状态/指纹集合时才被覆盖；**域外目标内容明确不在证明范围**（删除「已被 Git 覆盖」这种过强表述）。
- 用例：链接文本稳定 → 摘要不变；retarget → 摘要变；**目标内容变但文本不变 → 摘要不变（预期边界，须显式断言）**。

### ② 目录 / submodule —— **修正为**

- 真实目录：**稳定排序 + 长度分隔**的直接条目名集合哈希（不依赖 `scandir` 枚举顺序）；**禁止跟随 Windows reparse/junction**（`scandir` 前检查 `FILE_ATTRIBUTE_REPARSE_POINT`/reparse tag），reparse 目录单独标识或令指纹不可用。
- submodule：不在目录分支里扫描，在 `worktree_fingerprint` 层识别 mode `160000`，记录 **superproject gitlink OID**，并记录已检出 submodule HEAD 或「不可确认」状态。
- 用例：条目顺序无关、新增/删除直接条目、reparse 不进 `scandir`、不可读目录 → 指纹不可用、gitlink/checked-out HEAD 变化。

### ③ 锁键位宽 —— **修正为 128 bit + 迁移期双锁**

- 位宽：`sha256(norm_target).hexdigest()[:32]`。
- 迁移：**不能只清锁目录**。新版本必须在固定顺序（旧 16-hex 先、新 32-hex 后）**同时持有两把锁**，任一获取失败即释放已持锁并失败；确认旧版本进程全部退场后才移除旧锁兼容。
- 理由：单个未持有的旧锁文件残留无约束力；危险在于旧版本进程持 16-hex、新版本持 32-hex，同一 target 被两把锁同时放行。

### ④ `proof_failure` 归类 —— **采纳（并修正档位数量）**

- `merge()` 只声明三值 kind：`evidence_failure`（未执行合并）/ `merge_conflict`（wt 非零）/ `proof_failure`（可能已改现场但回执或后验不成立）。
- cleanup 固定 **四个** keeper 桶（见 §1 表）。
- 契约固化：三种 kind + 四个桶 + `run_all` 四个 cleanup 构造点，全部用集合相等断言覆盖。

### ⑤ 第三方 Git 并发窗口 —— **修正为「观察性证明 + 可选 CAS」**

- 短期：保留现有前后双采样作**异常检测**，**不得表述为第三方并发下的唯一因果证明**；`_MergeLock` 对人工 Git/IDE 无约束力（只约束遵守同一 sidecar 协议的本进程）。
- 若规范要求硬因果：改为「临时 ref 生成候选结果 → `git update-ref <target> <candidate> <expected-old-sha>` 原子 compare-and-swap」，`expected old` 不匹配即 `proof_failure` 并保留现场。
- 必补负例：**第三方在窗口内合入了同一 source**（现有 `progressed + content_changed + ff_ok` 仍可能通过）。

### ⑥ 永久 `unknown` / `wrong_type` 出口 —— **采纳**

- 新增纯只读 `doctor(batch_dir)` + `doctor` 子命令：输出 task、路径四态、分支三态、worktree 登记、底层错误、只读复核命令。
- **不得**调用 `wt_remove` / `unlink` / `rmdir` / 分支删除（删除属高危动作，由人执行）。
- 用例：四态枚举、异常详情、零写入、JSON schema。

### ⑦ fallback invocation —— **采纳**

- 删除 `find_done_tasks` 的**非显式 glob 分支**：`run_dirs is None` 直接 fail-closed；`merge` 同样拒绝缺 `run_dirs`/`expect_invocation`。
- 同步迁移：顶部用法示例（现仍写 `merge <批次目录> [--tasks ...]`，缺 `--invocation`/`--run-dir`，已失效）、18 处单测调用点、直接 Python API 调用。
- 保留：CLI 缺 `--run-dir` 返回 rc=2 的负例；新增函数层缺 `run_dirs` 的拒绝用例。
